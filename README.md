# Packaging Mindz - One Page Landing Page

Upload everything in this folder (index.html, style.css, robots.txt, sitemap.xml, images/) to the root of a GitHub Pages repository.

Before publishing, replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `index.html`, `robots.txt`, and `sitemap.xml` with the real GitHub Pages URL.

All images are local files in `images/`. The service illustrations are original SVGs and can be replaced with real photos of your products (keep the same filenames or update the `src` in index.html).
